# RELand Demo: Landmine Risk Estimation Web App

This interactive web-based demo simulates how the RELand model predicts landmine risk using AI, deep learning, and geospatial indicators. 

It visualizes risk levels using a topographic grid, with overlays for low, medium, and high-risk areas based on key features such as:

- Distance to roads
- Proximity to historical landmine events
- Terrain/topographic data
- Community-level conflict indicators

### 🚀 How to Use
1. Adjust thresholds with sliders
2. Click “Randomize Risk” to generate new predictions
3. Click on any grid cell to see detailed feature-based explanations
